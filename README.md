# CloudTodo

## About
CloudTodo is a simple Laravel-based To-Do API containerized using Docker for easy deployment and scalability.

## Features
- RESTful API for managing to-do items.
- Containerized with Docker for seamless setup.
- Built with Laravel for robust backend functionality.

## Requirements
- Docker
- Docker Compose

## Setup
1. Clone the repository:
    ```bash
    git clone https://github.com/nasghoi/laravel-todo-api.git
    cd cloudtodo
    ```
2. Build and start the containers:
    ```bash
    docker-compose up -d --build
    ```
3. Access the application at `http://localhost:8000`.

## Usage
- Use the API endpoints to create, read, update, and delete to-do items.
- Refer to the API documentation for detailed usage.
